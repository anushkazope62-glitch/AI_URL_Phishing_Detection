ℹ️ ABOUT THE PROJECT

AI URL Security Scanner

A machine-learning based system designed to identify potentially malicious URLs.

🤖

Machine Learning

A Random Forest classification model analyzes URL-based features to classify URLs as phishing or legitimate.

🔎

URL Analysis

The system examines characteristics such as URL length, HTTPS usage, domain patterns, suspicious keywords and obfuscation.

⚡

FastAPI Backend

FastAPI provides the API layer connecting the web interface with the machine learning prediction system.

🛡️

Security Awareness

The application helps users identify suspicious URLs before interacting with potentially harmful websites.

⚠️ Security Disclaimer

This application is a machine-learning based security prototype. A "Legitimate" result does not guarantee that a website is completely safe. Users should always verify unfamiliar websites before entering sensitive information.
